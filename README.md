# Fatemeh Aghaei Personal Website

This repository contains the source code for my personal website:

https://aghaeifatemeh.github.io/

The site is a compact portfolio and CV landing page for my work as a data analyst, with a background in pharmaceutical quality control and bioinformatics.

## What The Website Covers

The homepage highlights:

- My current work as a Data Analyst at Danone Specialized Nutrition Research & Innovation
- Earlier work in GMP quality control and laboratory digitalization at Johnson & Johnson
- Volunteer data analysis with Statistics Without Borders
- My MSc Bioinformatics from the University of Birmingham and selected projects
- Skills in Python, SQL, R, Databricks, Git/GitHub and Quarto
- A public CV link with a privacy-safe version of my CV

## How It Is Built

This is a Jekyll site designed for GitHub Pages. The source lives in the root of the repository, with styles, scripts, images, and the CV organized in simple project folders.
